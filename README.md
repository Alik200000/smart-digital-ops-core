# Smart Digital Group — Ops & Profit Intelligence System

Полная сквозная система автоматизации внутренних процессов и финансово-управленческого учета компании **Smart Digital Group**.

🌐 **Живое демо (Production Live):** [https://smart-digital-ops-core.onrender.com](https://smart-digital-ops-core.onrender.com)  
📂 **GitHub репозиторий:** [https://github.com/Alik200000/smart-digital-ops-core](https://github.com/Alik200000/smart-digital-ops-core)

Разработано для позиции **Vibe Coder / AI Automation Developer**.

---

## 🎯 Автоматизированный бизнес-цикл

Система закрывает полный цикл работы агентства без разрозненных сервисов:
1. **Лид → Контакт → Встреча → КП → Договор:**
   - Канбан-воронка в CRM с отслеживанием стадий.
   - Алгоритмический / AI-генератор сметы и коммерческого предложения за 2 секунды.
2. **Автоматический Handoff в 1 клик:**
   - При переводе сделки в статус «Won / Договор подписан» система автоматически:
     - Разворачивает проект в производственном реестре.
     - Фиксирует плановый бюджет и лимиты часов команды.
     - Создает счет на аванс 50% и начисляет предоплату в кассу.
3. **Учет работы команды и фактической себестоимости:**
   - Логирование рабочих часов специалистов по внутренним ставкам (AI Vibe Coder — 12 000 ₸/ч, Backend — 14 000 ₸/ч, PM — 9 000 ₸/ч, QA — 8 000 ₸/ч).
   - Автоматический учет прямых расходов (серверы, токены OpenAI, подрядчики) и накладных расходов (Overhead 15%).
4. **Контроль дебиторской задолженности и кассовых разрывов:**
   - Реестр счетов, статусы оплат, учет просроченной дебиторки (>14 дней).
5. **P&L и управленческая отчетность:**
   - Сквозной расчет маржинальности и чистой прибыли по каждому проекту, клиенту и направлению (AI-автоматизация, Web/Low-code, Маркетинг).
   - Выявление утечек прибыли (Scope Creep, превышение сметы часов).
   - Экспорт отчетов в формате CSV (совместим с Excel).

## 🚀 Быстрый запуск

### Вариант 1 (В 1 клик на Windows):
Дважды кликните по файлу **`start.bat`**.  
Скрипт автоматически запустит сервер и откроет систему в вашем браузере по адресу `http://localhost:3000`.

### Вариант 2 (Через терминал):
```bash
npm start
```
Откройте браузер: [http://localhost:3000](http://localhost:3000)

## 🛠 Технологический стек (Vibe Coding / Low-Code Architecture)

- **Backend:** Node.js, Express, REST API.
- **База данных:** JSON-хранилище `data/db.json` с мгновенной реактивностью и персистентностью.
- **Frontend:** Single Page Application (SPA), Tailwind CSS, Vanilla JS, адаптивный белый enterprise-дизайн.
- **Интеграционный потенциал:** Архитектура готова к подключению webhook-шлюзов **n8n**, базы данных **Supabase (PostgreSQL)** и внешних CRM (AmoCRM / Bitrix24).

## 📡 REST API Эндпоинты

- `GET /api/dashboard` — сводные KPI (выручка, себестоимость, маржа %, дебиторка, направления, алерты).
- `GET /api/projects` — список всех проектов с рассчитанными P&L показателями.
- `POST /api/projects` — создание нового проекта.
- `POST /api/projects/:id/timelogs` — фиксация отработанных часов с мгновенным пересчетом себестоимости.
- `GET /api/leads` — воронка CRM лидов.
- `POST /api/leads` — создание лида.
- `PUT /api/leads/:id` — смена стадии лида.
- `POST /api/leads/:id/convert-to-project` — сквозной Handoff (конвертация сделки в проект).
- `GET /api/invoices` — реестр счетов и дебиторки.
- `PUT /api/invoices/:id/pay` — проведение оплаты счета.
- `POST /api/ai/generate-kp` — генерация КП и структуры сметы по брифу.
- `GET /api/export/pnl` — экспорт финансового отчета в CSV.
